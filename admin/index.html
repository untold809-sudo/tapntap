Force update

Checked by the app on every launch. Old versions below the minimum are blocked when "Force" is on.

Remote config

A JSON object the app downloads at most once per refresh interval and caches. Use simple keys: true/false, numbers, text.

App addresses

Leave empty to use the address built into the app. The app picks up a change at its next config check, then uses it from the following launch.

Keep the old server running until every player has checked in (at least the refresh interval). Only https and these hosts are accepted: *.sonu77bodat.workers.dev, tapntap.dpdns.org, tapntap.com. Another domain needs one app release.

Grants

Give free coins or power-ups. One player (uuid or username) or every active player. Re-sending the same campaign id never double-credits.
